# JobHub - Personal Job Application Tracker
Fullstack MERN app - LinkedIn/Naukri jaisa job board nahi, personal CRM hai.

## Tech Stack
- Frontend: React + Vite + Tailwind + React Router
- Backend: Node.js + Express + MongoDB + Mongoose
- State: Context API + Axios

## Setup
1. Backend:
cd server
npm install
cp .env.example .env (MONGO_URI, PORT, JWT_SECRET dalo)
npm run dev

2. Frontend:
cd client
npm install
npm run dev

API runs on http://localhost:5000
Client runs on http://localhost:5173
